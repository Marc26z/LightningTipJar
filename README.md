## What's a Lightning Address?
A lightning address is like an email address. In fact, it looks like an email address, but these addresses allow people to send bvalue at the speed of light using bitcoin, a peer-to-peer electronic cash system. Notice how I describe it using the word cash, as in cash money. That's what bitcoin is, cash money on the Internet. 

### What Is The Purpose Of The Lightning Tip Jar
This is not some chart with squiggly lines people use to gamble for more fiat currency. This is a tool to help people to tip people using bitcoin. The employees can either use this to buy coffee, milk, or whatever they want. It is accepted at over 4 million square merchants in the United States. The restaurant Steak N Shake also accepts bitcoin at all locations in the United States. **The idea of the bitcoin tip jar is to allow employees at places like Steak N Shake to build their own personal bitcoin treasury by collecting tips**.

#### What If I Don't Have A Lightning Address?

Good news. It's easier than ever.
You can obtain a lightning address by choosing one of several apps. Here is a list of some of the ones I have tested but there are more.

**Self-Custodial**
-[Wisp](https://wisp.mobile/) This is also a user friendly nostr client and wallet with an easy backup.
- [Primal](https://primal.net/downloads) This is also a nostr client.
- [Breez](https://breez.technology/glow/) This is both an app and progressive web app. It also uses google Passkey's as a backup. Ut's not ideal for cypherpunks, but easy for everyone else.
- [BTCpayServer](https://btcpayserver.org/) This is an awesome point of sale terminal, but you need to be a little technical to run it.
- [AlbyHub](https://getalby.com/merchant-bitcoin-wallet) This is great if you are a little technical or run an out of the box node. If not, you can also pay for a cloud service that makes it super easy

  **Non-Custodial**
  If you are not comfortable holding your own keys or just want to easily be able to use bitcoin as money in places that do not accept bitcoin directly, try these:
  -[Cash App](https://cash.app/) - The Cash App offers a lightning address. I think you need to buy bitcoin before you can use it. but I'm not sure how that works. Some have cash app lightning addresses and some do not. I am not sure why.
  - [Strike](https://strike.me/) Strike gives a lightning address to every customer.
